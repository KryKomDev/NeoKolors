# NeoKolors Examples

This directory contains examples of how you can use NeoKolors.

- [Example App](./ExampleApp.cs) - A simple example app that demonstrates how to use the NeoKolors 
  TUI Framework for apps.
- [Example 2D Game](./ExampleGame2D.cs) - A simple example 2D game that demonstrates how to use the 
  NeoKolors TUI Framework for 2D games.
