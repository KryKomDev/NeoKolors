---
uid: NeoKolors.Common
summary: *content
---

`NeoKolors.Common` namespace is the foundation for the NeoKolors ecosystem. It provides optimized primitives,
structures, and utilities for working with console colors, styles, ANSI sequences, and advanced graphic rendering
formats like Sixel.

---
uid: NeoKolors.Console
summary: *content
---

`NeoKolors.Console` contains the primary output driver, input processor, log management framework, and exception
formatter for the NeoKolors ecosystem. It provides low-level terminal controls combined with advanced diagnostics.
