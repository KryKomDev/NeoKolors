# DocFX Documentation Guide

NeoKolors uses [DocFX](https://dotnet.github.io/docfx/) combined with the custom **Dokfx** theme to generate its public documentation website.

## Prerequisites

DocFX reads compiled release assemblies (`net10.0`) defined in `Docs/docfx.json`:
- Before updating metadata, build the solution in `Release` configuration:
  ```bash
  dotnet build NeoKolors.slnx -c Release
  ```

## Generating & Serving Docs

### 1. Update Dokfx Template
If the Dokfx theme needs updating:
- Windows (PowerShell):
  ```powershell
  cd Scripts
  ./update-dokfx.ps1
  ```
- Linux / macOS:
  ```bash
  cd Scripts
  ./update-dokfx.sh
  ```

### 2. Generate Documentation Metadata
```bash
docfx metadata Docs/docfx.json
```

### 3. Build Documentation Site
```bash
docfx build Docs/docfx.json
```

### 4. Serve & Preview Locally
```bash
docfx Docs/docfx.json --serve
```
The site will be hosted locally at `http://localhost:8080`.

## Documentation Structure
- `Docs/index.md`: Homepage overview.
- `Docs/articles/`: Conceptual guides, design documents, and project structure explanations.
- `Docs/api/`: Autogenerated API documentation generated from XML doc comments in C# sources.
- `Docs/filterConfig.yml`: Namespace and API inclusion/exclusion filters.
